## Class Name: Pop Songs
## Class Description: The class represents the varying released songs or music in one genre (Pop)
## Properties
| Property       | Data Type | Description                     |
|----------------|-----------|---------------------------------|
| title          | string    | the title of the song           |
| release year   | integer   | the year that it was released   |
| length of song | integer   | How long the song is in seconds |
| singer         | string    | who sang the song               |
## Methods
| Method                    | Description                                                  |
|---------------------------|--------------------------------------------------------------|
|play()                     | a method that plays the song                                 |
|stop()                     | a method that stops the song from playing                    |
|loopsong(numberofloops:int)| a method that asks how many times the song will be looped for|
